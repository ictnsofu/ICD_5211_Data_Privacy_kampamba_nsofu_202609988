This laboratory investigates the design of a privacy-preserving data platform for MosiPay, a fictional regional payment-switch analytics provider. The assessment focuses on the responsible management, processing, analysis and controlled disclosure of transaction-host data.

The principal objective is to develop and evaluate an architecture that supports legitimate internal analytical reporting while minimising the exposure of sensitive transaction and account-related information.

The laboratory addresses the following objectives:

Profile the supplied transaction-host dataset to establish its structure, data quality, physical characteristics and potential privacy risks.
Design a purpose-limited data architecture covering ingestion, quarantine, Bronze, Silver and Gold processing layers, controlled statistical release and data deletion.
Develop an executable data contract specifying field-level classifications, validation requirements, permitted purposes, access roles and retention categories.
Demonstrate data validation, access restrictions, quarantine decisions and security controls through executable tests.
Examine the risks associated with direct identifiers, indirect identifiers, account-level linkage and external information.
Document architectural decisions, threats, residual risks and the trade-offs between analytical utility and privacy protection.
